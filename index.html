ตั้งค่าการเชื่อมต่อ Google Sheets API (เฉพาะ Admin)

เชื่อมต่อฐานข้อมูล Google Sheets ผ่าน Google Apps Script Web App

ขั้นตอนการเชื่อมต่อ Google Sheets:
  1. เปิด Google Sheet ของคุณ แล้วไปที่ ส่วนขยาย (Extensions) > Apps Script
  2. นำโค้ดในไฟล์ backend/Code.gs ไปวางแทนที่แล้วกดบันทึก
  3. คลิก ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)
  4. เลือกประเภท เว็บแอปพลิเคชัน (Web app), กำหนด ผู้มีสิทธิ์เข้าถึง (Who has access) เป็น ทุกคน (Anyone)
  5. คัดลอก URL เว็บแอป (ที่ลงท้ายด้วย /exec) มาวางในช่องด้านบน
